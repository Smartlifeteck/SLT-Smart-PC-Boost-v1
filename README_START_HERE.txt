HOW TO START SLT Smart PC Boost:
1. Extract the complete repository folder to a local directory on Windows 10/11.
2. Double-click RUN_SMART_PC_BOOST.cmd.
3. Approve the Windows Administrator (UAC) prompt when you intentionally
   want to use administrator-level diagnostics, installs, or optimization tools.
4. On first use of Hardware QC Lock, create your own local staff PIN
   (stored as a salted PBKDF2 hash — no hardcoded default PIN is used).

SAFETY REMINDER:
- Always test system-changing operations (Boost, Appx removal, Sysprep)
  in a VM or non-production Windows device before using on customer PCs.
- Desktop shortcuts are NOT created or deleted automatically on launch;
  use the explicit button inside the app if you want a Desktop icon.
- For full safety details, read README.md and docs/PHASE1_SECURITY_HARDENING.md.
