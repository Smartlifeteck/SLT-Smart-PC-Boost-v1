# Getting Support

Thank you for using **SLT Smart PC Boost**!

## Community & Technical Help

- **Bug Reports:** Open a [Bug Report](.github/ISSUE_TEMPLATE/bug_report.yml) on GitHub Issues with redacted logs (`STARTUP_ERROR.txt`) and your Windows version.
- **Feature Ideas & Questions:** Open a [Feature Request](.github/ISSUE_TEMPLATE/feature_request.yml) or start a topic in GitHub Discussions.
- **Security Vulnerabilities:** Do **not** post publicly — follow [SECURITY.md](SECURITY.md).
